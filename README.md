# Module 2 – Linux, Networking & Cloud Infrastructure

This repository contains my practical work for **Module 2: Linux, Networking & Cloud Infrastructure** under the CodeMax Digital Solutions training program.

## Objectives

- Practice Linux Command Line Interface (CLI)
- Work with files and directories
- Configure Linux file permissions
- Manage users and groups
- Monitor processes and services
- Generate and work with SSH keys
- Understand IP addressing and DNS
- Check network ports
- Configure Linux firewall rules
- Configure AWS Security Groups
- Deploy a Linux server on AWS EC2
- Deploy and test a web service
- Verify connectivity to the deployed service

## Technologies & Tools

- Linux / Ubuntu
- AWS EC2
- AWS VPC
- AWS Subnet
- AWS Security Groups
- SSH
- Nginx
- UFW
- GitHub
